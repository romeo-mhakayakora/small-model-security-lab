# Research Question

A pipeline is not a contribution. Pick something testable.

## Candidates

1. Does evidence-based SFT on a small model reduce false positives compared with label-only SFT?
2. How much detection quality does 4-bit quantization cost at a fixed memory budget?
3. Does fine-tuning on C/C++ transfer to Python or JavaScript web code?
4. Does a verification step (scanner plus reproduction test) cut false positives enough to offset its cost?
